## 📤 Contributing

<details>
<summary><b>How to add resources</b></summary>

### Option A: Upload PDFs

```
EA2700A/
├── EA2700A_Mid_2024.pdf
├── EA2700A_End_2023.pdf
└── EA2700A_Notes_TopicX.pdf
```

### Option B: Add Drive Links (Recommended)

Add your Google Drive share link to the table above following the existing format.

**📝 Naming Convention**

- For exams: `EA2700A_Mid_YYYY.pdf` or `EA2700A_End_YYYY.pdf`
- For notes: `EA2700A_Lecture#_Topic.pdf`
- For assignments: `EA2700A_Assignment#_YYYY.pdf`

> 💡 **Important:** Only add files you have permission to share
