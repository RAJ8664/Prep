## 📤 Contributing

<details>
<summary><b>How to add resources</b></summary>

### Option A: Upload PDFs

```
MOOCS-N/
├── MOOCS-N_Mid_2024.pdf
├── MOOCS-N_End_2023.pdf
└── MOOCS-N_Notes_TopicX.pdf
```

### Option B: Add Drive Links (Recommended)

Add your Google Drive share link to the table above following the existing format.

**📝 Naming Convention**

- For exams: `MOOCS-N_Mid_YYYY.pdf` or `MOOCS-N_End_YYYY.pdf`
- For notes: `MOOCS-N_Lecture#_Topic.pdf`
- For assignments: `MOOCS-N_Assignment#_YYYY.pdf`

> 💡 **Important:** Only add files you have permission to share
